## 2. 기능 아이디어

### 기능 A: "평범한 경험도 특별하게" 변환기

**핵심**: "대단한 경험이 없어도 된다. 관점을 바꾸면 된다."

```
[사용자 입력] "편의점 알바 1년"

[AI 무기 분석]
→ W06 소통/설득 (82%) - "까다로운 고객 응대 → 소통 능력"
→ W05 문제해결 (75%) - "재고 관리 비효율 발견 → 개선 제안"
→ W07 성장/학습 (68%) - "단순 반복에서 효율화 방법을 스스로 터득"

→ 질문으로 더 발굴:
  "가장 힘들었던 고객은 어떤 분이었나요?"
  "혹시 '이건 비효율적이다' 싶었던 게 있었나요?"
```

### 기능 B: "자소서 문항 해독기"

**핵심**: "문항이 정말 묻는 건 따로 있다"

```
[문항] "본인이 속한 조직에서 갈등이 있었던 경험과 해결 과정을 서술하세요 (500자)"

[AI 해독]
- 표면적 질문: 갈등 해결 경험
- 진짜 묻는 것:
  1. 조직 내 갈등을 피하지 않고 직면하는가? (성숙도)
  2. 어떤 방식으로 해결하는가? (소통 스타일)
  3. 결과적으로 조직에 기여했는가? (성과 지향)

- 필요 무기: W03 팀워크(주), W06 소통(부)
- 피해야 할 것: "제가 양보했습니다" (수동적)
- 좋은 구조: 상황(100자) → 갈등 원인 분석(100자) → 해결 행동(200자) → 결과+배운점(100자)
```

### 기능 C: "무기 레이더 차트" (시각화)

유저의 경험 보유 현황을 레이더 차트로 시각화:

```
       위기극복 ★★★★
  성장/학습 ★★★        리더십 ★★
  소통/설득 ★★★        팀워크 ★★★★
  문제해결 ★★★★        도전정신 ★★

[분석]
✅ 강한 무기: 위기극복, 팀워크, 문제해결
⚠️ 약한 무기: 리더십, 도전정신
💡 추천: "리더십 경험이 부족해요. 혹시 스터디나 동아리에서 주도한 적 없나요?"
```

## 3. 자동 분류가 적용되는 전체 플로우

```
[경험 입력 방식 3가지]
    |
    ├── ① 텍스트 자유 입력
    ├── ② AI 인터뷰 (대화형)
    └── ③ 폼 기반 (제목, 기간, 역할, 성과)
    |
    v
[AI 자동 분류 엔진]
    ├── STAR 구조 자동 추출
    ├── 무기 자동 태깅 (주 무기 + 부 무기)
    ├── 역량 키워드 추출
    └── 매칭 가능 문항 유형 추천
    |
    v
[경험 카드 생성]
    ┌─────────────────────────────────┐
    │ 편의점 알바 (2024.03~2025.02)    │
    │                                 │
    │ 주 무기: 소통/설득                │
    │ 부 무기: 문제해결, 성장/학습       │
    │                                 │
    │ [S] 심야 시간대 1인 근무 + 고객 컴플레인 │
    │ [T] 고객 만족도 유지 + 재고 효율화   │
    │ [A] 고객 유형별 응대 매뉴얼 자체 제작 │
    │ [R] 컴플레인 50% 감소, 점장 인정     │
    │                                 │
    │ #소통 #문제해결 #자기주도 #고객응대  │
    │ 사용 이력: 삼성전자(팀워크 문항) ✓합격 │
    └─────────────────────────────────┘
    |
    v
[자소서 작성 시]
    문항 분석 → 필요 무기 판단 → 사용자 경험 중 매칭 → 적합도 순 추천
```

## 4. 기존 기획 대비 강화 포인트 요약

| 영역 | 기존 기획 | 강화 내용 |
|------|----------|----------|
| **경험 분류** | 역량 태그 자동 추출 (평면적) | → **7대 무기 체계 + 소분류** 구조화 |
| **프롬프트** | 코드 내 하드코딩 | → **DB 테이블 관리** + 버전 관리 + 성능 추적 |
| **문항 분석** | 간단한 의도 해석 | → **문항 해독기** (진짜 묻는 것 + 구조 가이드) |
| **경험 추천** | 적합도 % 단순 표시 | → **무기 기반 매칭** (문항→필요 무기→경험) |
| **시각화** | 없음 | → **무기 레이더 차트** (보유 현황 + 약점 보완) |
| **경험 발굴** | AI 인터뷰 (대화형) | → **"평범한 경험도 특별하게" 변환기** 추가 |
