# 무기 분류 체계 설계

> 작성일: 2026-02-09

---

## 1. 왜 "무기"인가?

취준생이 자소서를 쓸 때 가장 막히는 순간:
- "이 경험을 어디에 써야 하지?"
- "위기극복 소재가 없어..."
- "리더십 경험이 하나도 없는데..."

→ **경험을 넣으면 AI가 자동으로 "무기"(역량 카테고리)별로 분류**하고, 어떤 자소서 문항에 쓸 수 있는지 매핑해주는 시스템

---

## 2. Tier 1: 대분류 (7개 무기)

| 무기 코드 | 무기명 | 설명 | 빈출 자소서 문항 |
|-----------|--------|------|-----------------|
| `W01` | **위기극복** | 실패/좌절을 극복한 경험 | "실패를 극복한 경험", "어려움을 해결한 경험" |
| `W02` | **리더십** | 팀을 이끌거나 주도적으로 행동한 경험 | "리더십을 발휘한 경험", "주도적으로 해결한 경험" |
| `W03` | **팀워크/협업** | 타인과 협력하여 성과를 낸 경험 | "팀워크를 발휘한 경험", "갈등을 해결한 경험" |
| `W04` | **도전정신** | 새로운 것에 도전하거나 목표를 세워 달성한 경험 | "도전한 경험", "목표를 달성한 경험" |
| `W05` | **문제해결** | 분석적/창의적으로 문제를 해결한 경험 | "문제를 해결한 경험", "창의적인 방법으로..." |
| `W06` | **소통/설득** | 의사소통, 설득, 협상한 경험 | "갈등 상황에서 소통한 경험", "설득한 경험" |
| `W07` | **성장/학습** | 꾸준히 배우고 성장한 경험 | "성장과정", "자기개발 경험", "노력한 경험" |

---

## 3. Tier 2: 소분류 (무기별 세부 역량)

```
W01 위기극복
  ├── W01-A: 프로젝트 위기 (일정 지연, 팀원 이탈 등)
  ├── W01-B: 개인적 역경 (건강, 가정환경, 경제적 어려움)
  ├── W01-C: 실패 후 재도전 (시험 불합격, 사업 실패 등)
  └── W01-D: 예상치 못한 변수 대응 (코로나, 갑작스러운 변화)

W02 리더십
  ├── W02-A: 공식적 리더 (회장, 팀장, 조장)
  ├── W02-B: 비공식적 리더 (자발적 주도, 분위기 메이커)
  ├── W02-C: 의사결정 (어려운 선택, 방향 제시)
  └── W02-D: 동기부여 (팀원 독려, 사기 진작)

W03 팀워크/협업
  ├── W03-A: 갈등 해결 (의견 충돌 조율)
  ├── W03-B: 역할 분담/조율 (효율적 협업 구조)
  ├── W03-C: 다양성 존중 (다른 배경의 사람과 협업)
  └── W03-D: 시너지 창출 (1+1>2 성과)

W04 도전정신
  ├── W04-A: 새로운 영역 도전 (첫 경험, 새 분야)
  ├── W04-B: 높은 목표 설정 & 달성
  ├── W04-C: 창업/창작 (0→1 경험)
  └── W04-D: 자기 한계 돌파

W05 문제해결
  ├── W05-A: 분석적 접근 (데이터 기반, 논리적 분석)
  ├── W05-B: 창의적 접근 (새로운 방법, 발상 전환)
  ├── W05-C: 프로세스 개선 (비효율 발견 → 개선)
  └── W05-D: 기술적 문제해결 (개발, 엔지니어링)

W06 소통/설득
  ├── W06-A: 이해관계자 설득 (교수, 상사, 고객)
  ├── W06-B: 프레젠테이션/발표
  ├── W06-C: 경청과 공감
  └── W06-D: 협상/조율

W07 성장/학습
  ├── W07-A: 자기주도 학습 (독학, 자격증, 스터디)
  ├── W07-B: 멘토링/피드백 수용
  ├── W07-C: 가치관 형성 (인생관, 직업관)
  └── W07-D: 전문성 심화 (특정 분야 깊이 파기)
```

## 4. 자동 분류 로직

```
[사용자 입력: "동아리에서 축제 부스 운영을 맡았는데 팀원 2명이 갑자기 빠져서..."]
    |
    v
[AI 분류 엔진]
    |
    ├── 1차 무기: W01 위기극복 (85%) - "팀원 이탈"이라는 위기 상황
    ├── 2차 무기: W02 리더십 (72%) - "맡았는데"에서 주도적 역할
    └── 3차 무기: W03 팀워크 (65%) - 동아리 활동, 부스 운영
    |
    v
[경험 카드 생성]
    - 주 무기: 위기극복 (W01-A)
    - 부 무기: 리더십 (W02-B), 팀워크 (W03-B)
    - 매칭 가능 문항: "위기를 극복한 경험", "리더십을 발휘한 경험"
```
