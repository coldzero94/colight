## 1. MVP 최소 기능셋 (MFS) 정의

> "채용공고 URL 하나로 기업 분석 → 내 경험과 매칭 → 자소서 초안 코칭까지"

| 구분 | 기능 ID | 기능명 | MFS 포함 이유 |
|------|---------|--------|--------------|
| 인프라 | F23 | 프롬프트 DB | 모든 AI 기능의 기반 |

### MFS 제외 기능 (MVP에서 후순위로 이동)

| 기능 ID | 기능명 | 제외 이유 | 대체 방안 |
|---------|--------|----------|----------|
| F02 | AI 인터뷰 | 가치 검증에 필수 아님 | 폼 기반 직접 입력으로 충분 |
| F12 | 경험 추천 | F10 매칭 결과로 부분 대체 가능 | F10 결과에 간단한 추천 문구 추가 |
| F14 | 첨삭 코칭 | 초안 코칭만으로 핵심 가치 검증 가능 | Sprint 5에서 추가 |
| F25 | 공통 문항 패턴 DB | 없어도 문항 분석 가능 | AI가 실시간으로 문항 의도 분석 |

### MFS 사용자 시나리오

```
1. 회원가입/로그인
2. 내 경험 3개 등록 (폼 기반) → 자동 역량 태깅
3. 채용공고 URL 붙여넣기
4. 기업 분석 리포트 확인 (인재상, 동향, 전략 키워드)
5. 내 경험 적합도 매칭 확인 (경험별 %)
6. 자소서 문항 입력 → 문항 의도 분석 확인
7. 매칭된 경험 선택 → AI 초안 코칭으로 STAR 구조 초안 생성
→ "와, 이 기업 분석 대박이다. 더 쓰고 싶다" (Aha Moment → 유료 전환)
```
