## 카테고리 1: 경험 관리 (Experience Bank)

### F01. 경험 등록 (직접 입력) [P0]
- **사용자 스토리**: 취준생으로서 나의 경험을 체계적으로 등록하고 싶다, 자소서 작성 시 빠르게 꺼내 쓰기 위해
- **핵심 UX**: 경험 추가 → 폼 입력 (제목, 기간, 역할, 내용, 성과) → STAR 구조 자동 정리 → 경험 카드 생성
- **의존**: 없음

### F02. AI 경험 인터뷰 (대화형 입력) [P0]
- **사용자 스토리**: 어떤 경험을 써야 할지 모르겠을 때 AI와 대화하며 경험을 발굴하고 싶다
- **핵심 UX**: AI 인터뷰 시작 → 단계별 질문 → STAR 구조 자동 정리 → 사용자 확인/수정 → 경험 카드 생성
- **의존**: F01

### F03. 역량 태그 자동 분류 (무기 자동 태깅) [P0]
- **사용자 스토리**: 등록한 경험이 어떤 역량을 보여주는지 자동으로 분류받고 싶다
- **핵심 UX**: 경험 입력 완료 → AI 자동 분류 → 주 무기 + 부 무기 태깅 → 매칭 가능 문항 추천
- **의존**: F01

### F04. 경험 활용 이력 추적 [P1]
- **사용자 스토리**: 어떤 경험을 어디에 사용했는지 추적하고 싶다
- **핵심 UX**: 자소서 작성 시 경험 선택 → 자동 이력 기록 → 경험 카드에서 사용 이력 조회
- **의존**: F01, F10

### F05. 무기 레이더 차트 [P1]
- **사용자 스토리**: 7대 무기 보유 현황을 한눈에 보고 약한 역량을 파악하고 싶다
- **핵심 UX**: 경험 등록 후 → 레이더 차트 자동 생성 → 강한/약한 무기 분석 → 보완 추천
- **의존**: F01, F03

### F06. "평범한 경험도 특별하게" 변환기 [P1]
- **사용자 스토리**: 대단하지 않은 경험도 자소서 소재로 변환하고 싶다
- **핵심 UX**: 평범한 경험 입력 → AI 무기 분석 → 추가 질문으로 깊이 발굴 → 특별한 경험 카드로 재구성
- **의존**: F01, F03

## 카테고리 2: 기업 분석 (Company Intelligence)

### F07. 채용공고 자동 분석 [P0]
- **사용자 스토리**: 채용공고 URL만 넣으면 직무/자격요건/키워드를 자동 추출받고 싶다
- **핵심 UX**: URL 붙여넣기 → 실시간 파싱 → 분석 결과 표시
- **의존**: 없음

### F08. 기업 프로필 자동 조회 [P0]
- **사용자 스토리**: 지원 기업의 기본정보/재무현황/규모를 한번에 파악하고 싶다
- **핵심 UX**: 기업명 자동 인식 → DART API 연동 → 기업 정보 표시
- **의존**: F07

### F09. 인재상 분석 + 최근 동향 + 전략 키워드 [P0]
- **사용자 스토리**: 기업이 원하는 인재 특성과 자소서 키워드를 자동 분석받고 싶다
- **핵심 UX**: 기업 분석 요청 → 인재상 추출 + 뉴스 요약 + 전략 키워드 도출 → 리포트 완성
- **의존**: F07, F08

### F10. 내 경험 적합도 매칭 [P0]
- **사용자 스토리**: 내 경험이 특정 기업에 얼마나 적합한지 점수로 알고 싶다
- **핵심 UX**: 기업 분석 완료 → 경험 vs 요구사항 자동 매칭 → 적합도 % 표시
- **의존**: F01, F03, F07, F09

## 카테고리 3: AI 자소서 코칭

### F11. 자소서 문항 분석 (문항 해독기) [P0]
- **사용자 스토리**: 자소서 문항이 진짜 무엇을 묻는 것인지 해석받고 싶다
- **핵심 UX**: 문항 입력 → 표면적 질문 + 진짜 의도 + 필요 무기 + 좋은 구조(글자수 배분) → 경험 추천
- **의존**: F01, F03, F07

### F12. 경험 추천 (무기 기반 매칭) [P0]
- **사용자 스토리**: 특정 문항에 가장 적합한 경험을 자동 추천받고 싶다
- **핵심 UX**: 문항 분석 완료 → 필요 무기 판단 → 해당 무기 보유 경험 검색 → 적합도 순 추천
- **의존**: F01, F03, F11

### F13. 초안 코칭 (STAR 구조 초안 생성) [P0]
- **사용자 스토리**: 선택한 경험으로 STAR 구조 초안을 받고 싶다
- **핵심 UX**: 경험 선택 → AI 초안 제안 → 에디터에서 직접 수정 → 저장
- **의존**: F11, F12

### F14. 첨삭 코칭 [P0]
- **사용자 스토리**: 작성한 자소서에 대해 구체적인 피드백을 받고 싶다
- **핵심 UX**: 자소서 완료 → 4개 지표 점수 (구체성/직무적합/기업맞춤/진정성) → 개선 제안
- **의존**: F13

### F15. AI 탐지 체크 [P1]
- **의존**: F13

### F16. 글자수 조절 코칭 [P1]
- **의존**: F13

### F17. 무기별 경험 강화 코칭 [P1]
- **의존**: F01, F03, F09
