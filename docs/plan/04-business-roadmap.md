## 2. MVP 로드맵

### Phase 1: 핵심 루프 (1~2주)

**목표**: "URL 넣으면 기업 분석 나온다" + "경험 등록 가능"

- [ ] Supabase 프로젝트 셋업 (Auth + DB 스키마)
- [ ] Next.js 프로젝트 셋업 (Vercel 배포)
- [ ] 경험 등록 CRUD (폼 기반)
- [ ] 채용공고 URL 파싱 (Cheerio, 정적 사이트)
- [ ] DART API 연동 (기업 기본정보)
- [ ] AI 기업 분석 리포트 생성 (스트리밍)
- [ ] 분석 결과 캐싱

### Phase 2: 코칭 기능 (2~3주)

**목표**: "자소서 초안 코칭 + 첨삭" 가능

- [ ] AI 경험 인터뷰 (대화형)
- [ ] 경험 ↔ 기업 매칭 (적합도 점수)
- [ ] 자소서 문항 분석 + 경험 추천
- [ ] 초안 코칭 (STAR 기반)
- [ ] 첨삭 코칭 (구체성, 적합성, 맞춤도 점수)
- [ ] 네이버 뉴스 API 연동

### Phase 3: 대시보드 + 고도화 (3~4주)

**목표**: "지원 관리 + 피드백 루프"

- [ ] 지원 현황 칸반보드
- [ ] 자소서 버전 관리
- [ ] 합격/불합격 기록 + 인사이트
- [ ] Koyeb 워커 (원티드 동적 크롤링)
- [ ] 사람인 API 연동
- [ ] 결제 시스템 (토스페이먼츠)

### Phase 4: 성장 (4주~)

- [ ] 주요 대기업 인재상 사전 DB 구축
- [ ] 임베딩 기반 빠른 경험 매칭
- [ ] AI 탐지 체크 기능
- [ ] 모바일 최적화
- [ ] 공유/바이럴 기능

### MVP Phase ↔ 개발 Phase 매핑

| MVP 로드맵 | 개발 Phase | 설명 |
| --------- | --------- | ---- |
| Phase 1: 핵심 루프 (1~2주) | Phase 0~4 | 프로젝트 셋업, 인증, 경험 CRUD, 무기 태깅, 크롤링, 기업 분석, 매칭 |
| Phase 2: 코칭 기능 (2~3주) | Phase 5~6 | 문항 분석, 초안 코칭, 코칭 에디터, 첨삭 코칭 |
| Phase 3: 대시보드 + 고도화 (3~4주) | Phase 6.1~8.1 | 프리미엄, 랜딩/베타, AI 인터뷰, 칸반, 버전 관리 |
| Phase 4: 성장 (4주~) | Phase 9~10 | 결제 연동, 성장 기능 |

## 3. 핵심 성공 지표 (KPI)

| 지표 | 목표 | 측정 방법 |
|------|------|----------|
| 무료 → 유료 전환율 | 5~8% | 유료 결제 / 가입자 |
| 기업 분석 재사용률 | 70%+ | 2회 이상 분석한 사용자 비율 |
| 자소서 완성률 | 60%+ | 코칭 시작 → 자소서 제출까지 |
| NPS (추천 의향) | 40+ | 정기 설문 |
| 서류 통과율 개선 | 30%+ (vs 평균 22%) | 사용자 자기 보고 |

| 대형 플랫폼(사람인, 잡코리아)이 유사 기능 출시 | 경험 관리 + 기업 분석 + 코칭의 **통합 경험**으로 차별화 |
