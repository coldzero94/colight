## 1. 가격 모델: 건당/회차권 (취준생 최적)

| 상품 | 가격 | 포함 기능 | API 원가 | 마진 |
|------|------|----------|---------|------|
| **무료** | 0원 | 경험 등록 3개, 기업 분석 1회, AI 코칭 1회 | ~200원 | 고객 획득 비용 |
| **스타터 10회권** | 4,900원 | 기업 분석 10회 + AI 코칭 10회 | ~2,000원 | **59%** |
| **프로 30회권** | 12,900원 | 기업 분석 30회 + AI 코칭 30회 + 경험 무제한 | ~6,000원 | **53%** |
| **시즌패스 (3개월)** | 24,900원 | 무제한 사용 | ~15,000원 | **40%** |

> ⚠️ **시즌패스 비용 리스크**: 무제한 사용 시 헤비 유저가 수백 건을 사용하면 마진이 마이너스가 될 수 있음. 일일/월간 사용 상한(Fair Use Policy) 정의 필요.

### Freemium 전환 전략

```
[무료 체험]
    │  경험 3개 등록 + 기업 분석 1회 + AI 코칭 1회
    │  → "와, 이 기업 분석 진짜 좋다" (Aha Moment)
    ▼
[Paywall]
    │  "추가 기업 분석은 스타터 회원부터 가능해요"
    │  무료 결과 안에 프리미엄 분석 미리보기 (흐릿하게)
    ▼
[전환]
    전환율 목표: 5~8%
    핵심 트리거: 기업 분석 퀄리티 → 추가 사용 욕구
```

### 현실적 수익 시나리오

| 단계 | 기간 | 가입자 | 유료 전환 | 월 매출 | 월 순이익 |

| MVP 검증 | 1~3개월 | 500~1,000명 | 3~5% | 7~50만원 | 3~45만원 |

## 2. MVP 로드맵

### Phase 1: 핵심 루프 (1~2주)

**목표**: "URL 넣으면 기업 분석 나온다" + "경험 등록 가능"

- [ ] Supabase 프로젝트 셋업 (Auth + DB 스키마)
- [ ] Next.js 프로젝트 셋업 (Vercel 배포)
- [ ] 경험 등록 CRUD (폼 기반)
- [ ] 채용공고 URL 파싱 (Cheerio, 정적 사이트)
- [ ] DART API 연동 (기업 기본정보)
- [ ] AI 기업 분석 리포트 생성 (스트리밍)
- [ ] 분석 결과 캐싱

### Phase 2: 코칭 기능 (2~3주)

**목표**: "자소서 초안 코칭 + 첨삭" 가능

- [ ] AI 경험 인터뷰 (대화형)
- [ ] 경험 ↔ 기업 매칭 (적합도 점수)
- [ ] 자소서 문항 분석 + 경험 추천
- [ ] 초안 코칭 (STAR 기반)
- [ ] 첨삭 코칭 (구체성, 적합성, 맞춤도 점수)
- [ ] 네이버 뉴스 API 연동

### Phase 3: 대시보드 + 고도화 (3~4주)

**목표**: "지원 관리 + 피드백 루프"

- [ ] 지원 현황 칸반보드
- [ ] 자소서 버전 관리
- [ ] 합격/불합격 기록 + 인사이트
- [ ] Koyeb 워커 (원티드 동적 크롤링)
- [ ] 사람인 API 연동
- [ ] 결제 시스템 (토스페이먼츠)

### Phase 4: 성장 (4주~)

- [ ] 주요 대기업 인재상 사전 DB 구축
- [ ] 임베딩 기반 빠른 경험 매칭
- [ ] AI 탐지 체크 기능
- [ ] 모바일 최적화
- [ ] 공유/바이럴 기능

### MVP Phase ↔ 개발 Phase 매핑

| MVP 로드맵 | 개발 Phase | 설명 |
| --------- | --------- | ---- |
| Phase 1: 핵심 루프 (1~2주) | Phase 0~4 | 프로젝트 셋업, 인증, 경험 CRUD, 무기 태깅, 크롤링, 기업 분석, 매칭 |
| Phase 2: 코칭 기능 (2~3주) | Phase 5~6 | 문항 분석, 초안 코칭, 코칭 에디터, 첨삭 코칭 |
| Phase 3: 대시보드 + 고도화 (3~4주) | Phase 6.1~8.1 | 프리미엄, 랜딩/베타, AI 인터뷰, 칸반, 버전 관리 |
| Phase 4: 성장 (4주~) | Phase 9~10 | 결제 연동, 성장 기능 |

## 4. 유닛 이코노믹스 시나리오 분석

### Freemium 전환율 벤치마크

글로벌 B2C SaaS Freemium 전환율 (2025 벤치마크):
- **하위 25%**: 1-2%
- **중간값**: 2-5%
- **상위 25%**: 5-10%
- **AI 제품 상위**: 10-15% (30일 내 특정 코호트)

> ⚠️ 기존 가정(5-8%)은 낙관적. 보수적 시나리오(3%)를 기본으로 계획.

### 3가지 시나리오

| 지표 | 보수적 | 기본 | 낙관적 |
|------|--------|------|--------|
| **Year 1 가입자** | 5,000명 | 10,000명 | 20,000명 |
| **전환율** | 3% | 5% | 8% |
| **유료 사용자** | 150명 | 500명 | 1,600명 |
| **평균 ARPU** | 4,900원 | 5,500원 | 7,000원 |
| **월 매출** | ~74만원 | ~275만원 | ~1,120만원 |
| **무료 사용자 AI 비용** | ~97만원/월 | ~190만원/월 | ~370만원/월 |
| **영업이익** | **-23만원/월** | **+85만원/월** | **+750만원/월** |

> **무료 사용자 AI 비용 산출**: (가입자 - 유료 사용자) × 2회/월 × 200원 = 월 AI 원가
> 보수적 시나리오에서는 적자. 무료 사용량 제한 강화 또는 빠른 유료 전환 필요.

### CAC Payback Period

| 채널 | CAC | 유료 전환 시 월 ARPU | Payback |
|------|-----|---------------------|---------|
| 커뮤니티 (유기적) | ~0원 | 4,900원 | 즉시 |
| 대학 제휴 | ~500원 | 4,900원 | 0.1개월 |
| SEO/콘텐츠 | ~1,000원 | 4,900원 | 0.2개월 |
| 유료 광고 | ~3,000원 | 4,900원 | 0.6개월 |

> CAC payback은 양호. 핵심 리스크는 전환율이 3% 미만으로 떨어지는 경우.

### 무료 사용량 조정 권고

| 현재 | 조정안 | 근거 |
|------|--------|------|
| 경험 등록 3개 | 무제한 (무료) | 경험 축적 = 전환 비용 ↑, 매칭 품질 ↑ |
| 기업 분석 1회 | 1회 유지 | Aha Moment 트리거 (1회로 충분) |
| AI 코칭 1회 | 1회 유지 | 코칭 품질 체감 후 결제 유도 |

## 5. B2B2C 채널 전략

### 현재: B2C 단일 채널

```
[개인 사용자] → 가입 → 무료 체험 → 유료 전환
```

### 확장: B2B2C 복합 채널

```
[대학 커리어센터] → 학생 라이선스 구매 → 학생 무료 사용 → 개인 업그레이드
[취업학원/인강]   → 수강생 번들 제공  → 수강생 사용      → 추가 구매
[리크루팅 에이전시] → 도구로 활용     → 고객에게 제공     → 에이전시 구독
```

### B2B2C 가격 모델 (안)

| 채널 | 대상 | 가격 | 제공 내용 | 목표 |
|------|------|------|----------|------|
| **대학 커리어센터** | 학생 500명 | 월 50만원 (학생당 1,000원) | 기업 분석 5회/학생 + 코칭 3회/학생 | 3개교 파일럿 |
| **취업학원 제휴** | 수강생 | 수강료에 포함 (건당 500원 정산) | 기업 분석 3회 + 코칭 2회 | 2개 학원 |
| **대학 특강 연계** | 참석자 | 무료 체험 쿠폰 (3회권) | 기업 분석 3회 무료 | 브랜드 인지도 |

### B2B2C 실행 타이밍

- **Phase 6.2 (랜딩 & 베타)**: 3개 대학 커리어센터에 파일럿 제안서 발송
- **Phase 9 (결제 연동)**: B2B 결제 기능 추가 (대학 일괄 결제)
- **Phase 10 (성장)**: 10개 대학 확대 + 학원 2개 제휴

|--------|--------|------|
