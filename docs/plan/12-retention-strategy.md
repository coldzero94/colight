## 2. 리텐션 루프 설계

### 핵심 루프: 경험 축적 → 매칭 향상 → 성공 체감

```
[경험 등록]
    │
    ▼
[AI 무기 태깅] → "내 위기극복 역량이 강하구나!"
    │
    ▼
[기업 분석 & 매칭] → "이 경험이 이 기업에 적합도 92%!"
    │
    ▼
[코칭 & 제출]
    │
    ├── [성공] → "서류 통과!" → 면접 준비 유도
    │                           → 다른 기업 지원 유도
    │
    └── [미통과] → "피드백 기반 경험 보강" → 다시 루프
    │
    ▼
[경험 추가 등록] → "경험이 많을수록 매칭 정확도 UP"
    → 루프 반복
```

### 보조 루프: 데이터 축적 해자 (Data Moat)

```
[사용 기간 증가]
    │
    ▼
[개인화 데이터 축적]
    ├── 경험 Bank 확대 (5개 → 10개 → 20개)
    ├── 무기 프로필 정교화
    ├── 선호 기업/직무 패턴 학습
    └── 코칭 피드백 이력 누적
    │
    ▼
[매칭/코칭 품질 향상]
    │
    ▼
[전환 비용(Switching Cost) 증가]
    → "다른 서비스로 가면 처음부터 다시 해야 한다"
```

## 3. 단계별 리텐션 전략

### Phase 1: 활성화 (Day 0-7)

| 트리거 | 액션 | 채널 | 목적 |
|--------|------|------|------|
| 가입 직후 | 프로필 미완성 리마인더 | 인앱 배너 | 온보딩 완성 |
| 경험 0개 + D+1 | "첫 경험 등록 가이드" | 이메일 | 빈 상태 탈출 |
| 경험 1개 + D+2 | "기업 분석 체험해보세요" | 인앱 CTA | Aha Moment 도달 |
| 기업 분석 완료 + D+3 | "자소서 코칭을 받아보세요" | 이메일 | 코어 루프 진입 |

### Phase 2: 습관 형성 (Day 7-30)

| 트리거 | 액션 | 채널 | 목적 |
|--------|------|------|------|
| 경험 1-2개만 등록 | "경험 3개 이상이면 매칭 정확도 85%↑" | 인앱 | 경험 축적 유도 |
| 기업 분석 1회만 사용 | "비교 분석: 두 기업 분석 결과 비교" | 이메일 | 추가 분석 유도 |
| 3일 미접속 | "작성 중인 자소서가 기다리고 있어요" | 이메일 | 재방문 |
| 코칭 1회 완료 | "첨삭 받으면 구체성 점수 평균 40%↑" | 인앱 | 다음 단계 유도 |

### Phase 3: 충성 유지 (Day 30+)

| 트리거 | 액션 | 채널 | 목적 |
|--------|------|------|------|
| 7일 미접속 | "이번 주 새로운 채용공고 N건" | 이메일 | 시즌 중 이탈 방지 |
| 마감일 D-7 | "[기업명] 마감 7일 전!" | 이메일+인앱 | 긴급성 부여 |

| 프로 사용량 50% 소진 | "남은 횟수: N회 — 추가 구매 혜택" | 인앱 | 업셀 |

## 4. 비수기 전략 (Revenue Smoothing)

### 여름 비시즌 (7-8월): "경험 정리 시즌"

| 프로그램 | 설명 | 수익 모델 |
|---------|------|----------|
| **7일 경험 정리 챌린지** | 매일 1개 경험을 STAR로 정리하는 미션 | 무료 (경험 데이터 축적) |
| **AI 인터뷰 연습** | 대화형 경험 정리 (Phase 7) | 무료 3회, 이후 유료 |
| **무기 프로필 분석** | 보유 경험 기반 종합 역량 리포트 | 스타터 이상 |
| **인턴 지원 코칭** | 하계 인턴 공채 대응 | 스타터 이상 |

### 겨울 비시즌 (12-2월): "목표 설정 시즌"

| 프로그램 | 설명 | 수익 모델 |
|---------|------|----------|
| **신년 취업 목표 플래너** | 목표 기업 리스트업 + 역량 갭 분석 | 무료 |
| **직무 탐색 코칭** | AI 기반 적합 직무 추천 | 프로 이상 |
| **이력서/포트폴리오 정리** | 경험 Bank 기반 이력서 자동 생성 | 프로 이상 |
| **상반기 공채 프리뷰** | 주요 기업 채용 일정 + 작년 트렌드 | 무료 (SEO 콘텐츠) |

### 비수기 수익 보전 전략

```
비시즌 월매출 목표: 피크의 30-40% 유지

방법:
1. 연간/시즌 구독 판매 (상시 매출)
   → "시즌패스 3개월" 상반기 시작 전 판매
   → 비수기에도 구독 매출 유지

2. 비수기 한정 프로모션
   → "여름 미리 준비 할인" (프로 30회 9,900원)
   → 비수기 가입자 확보 + 시즌 전환 시 리텐션

3. 콘텐츠 매출
   → "기업별 인재상 프리미엄 리포트" 단건 판매 (1,900원)
   → SEO 유입 → 단건 구매 → 시즌 시 서비스 전환
```

## 5. 취업 후 확장 (Post-Hire Value)

### 현재 문제: 취업 성공 = 서비스 이탈

```
취업 성공 → Colight 사용 중단 → LTV 종료
```

### 해결: 커리어 전주기 가치 제공

```
취업 준비 → [취업 성공] → 입사 적응 → 이직 준비
                ↓
    ┌─────────────────────────────┐
    │ Post-Hire 기능 (Phase 10+)  │
    │                             │
    │ 1. 면접 준비 코칭            │
    │    (서류 통과 직후 자동 유도)  │
    │                             │
    │ 2. 입사 후 자기소개 작성      │
    │    "부서 배치 첫 자기소개"    │
    │                             │
    │ 3. 업무 회고 경험 기록        │
    │    (이직 시 활용 가능)        │
    │                             │
    │ 4. 이직 시 경험 재구성        │
    │    "기존 경험 + 직장 경험     │
    │     → 새 직무 맞춤 정리"     │
    └─────────────────────────────┘
```

### 단기 적용 가능 항목 (MVP 후 1-2 스프린트)

| 기능 | 구현 난이도 | 리텐션 효과 | 우선순위 |
|------|-----------|-----------|---------|
| 면접 준비 질문 생성 (기업 분석 기반) | 낮음 (기존 파이프라인 재활용) | 높음 | P1 |
| 입사 자기소개 코칭 | 낮음 (프롬프트만 추가) | 중간 | P2 |
| 업무 경험 기록 (간편 메모) | 중간 (새 UI) | 높음 | P1 |
| 연봉 협상 코칭 | 중간 | 중간 | P3 |

## 6. 이탈 방지 전술

### Churn 예측 신호

| 신호 | 위험도 | 대응 |
|------|--------|------|
| 7일 미접속 + 작성 중 자소서 있음 | 높음 | "마감일 임박" 이메일 발송 |
| 14일 미접속 | 높음 | "새 채용공고 N건" + 할인 쿠폰 |
| 유료 → 무료 다운그레이드 | 매우 높음 | 다운그레이드 사유 설문 + 1회 무료 연장 제안 |
| 계정 삭제 시도 | 최종 | 데이터 내보내기 안내 + 30일 유예 |

### Win-Back 캠페인

| 이탈 기간 | 대상 | 메시지 | 인센티브 |
|----------|------|--------|---------|
| 30일 | 경험 3개+ 보유 사용자 | "등록한 경험 N개가 매칭을 기다리고 있어요" | 분석 1회 무료 |
| 60일 | 유료 경험 있는 사용자 | "하반기 공채 시즌 시작! 미리 준비하세요" | 스타터 50% 할인 |
| 90일+ | 모든 이탈 사용자 | "Colight가 업데이트되었어요 (신규 기능)" | 프로 2주 체험권 |
