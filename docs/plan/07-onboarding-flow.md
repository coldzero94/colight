## 1. 최초 가입 직후 플로우

### 전체 온보딩 여정

```
[회원가입 완료]
    │
    ▼
[Step 1: 프로필 설정] ──── 스킵 가능, 60초 이내 완료 목표
    │  기본 정보 + 목표 설정
    │
    ▼
[Step 2: 첫 경험 등록 유도] ──── 핵심 전환점
    │  빈 상태 CTA + 가이드
    │
    ▼
[Step 3: 샘플 기업 분석 체험] ──── Aha Moment
    │  "이 서비스 진짜 좋다" 체감
    │
    ▼
[대시보드 진입] ──── 자유 탐색
```

### Step 1: 프로필 설정

2단계 구성, 총 60초 이내 완료 가능하도록 설계:

**1단계: 기본 정보**

| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| 닉네임 | 텍스트 | 필수 | 서비스 내 표시명 |
| 학년/상태 | 셀렉트 | 필수 | 대학교 1~4학년 / 졸업생 / 직장인 |

**2단계: 목표 설정**

| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| 희망 직무 | 셀렉트 (다중) | 선택 | 마케팅, 개발, 기획, 영업, 재무 등 |
| 희망 산업 | 셀렉트 (다중) | 선택 | IT, 금융, 제조, 유통 등 |
| 관심 기업 규모 | 셀렉트 | 선택 | 대기업 / 중견기업 / 스타트업 / 공기업 |

> **스킵 정책**: 2단계(목표 설정)는 스킵 가능. 단, 완료 시 "맞춤 추천 품질이 높아집니다" 안내와 함께 프로그레스 바로 완성도 표시.

### 프로필 미완성 시 리마인더

```
[대시보드 상단 배너]
┌───────────────────────────────────────────────────┐
│ 💡 프로필을 완성하면 맞춤 추천 품질이 높아져요!     │
│    진행률: ████████░░ 80%                          │
│    [프로필 완성하기]                                │
└───────────────────────────────────────────────────┘
```

## 2. 첫 경험 등록 유도

> 경험 0개 상태에서의 이탈을 방지하는 것이 가장 중요한 전환점

### 빈 상태(Empty State) 디자인

```
┌───────────────────────────────────────────────────┐
│                                                   │
│          📋 아직 등록된 경험이 없습니다              │
│                                                   │
│    자소서 코칭을 받으려면 먼저 경험을 등록해주세요.    │
│    인턴, 프로젝트, 대외활동, 아르바이트 등           │
│    어떤 경험이든 좋습니다!                          │
│                                                   │
│    ┌──────────────────┐  ┌──────────────────┐    │
│    │  ✏️ 직접 입력하기  │  │  💬 AI와 대화로   │    │
│    │                  │  │    정리하기       │    │
│    └──────────────────┘  └──────────────────┘    │
│                                                   │
│    "어떤 경험을 써야 할지 모르겠다면              │
│     AI 인터뷰를 추천드려요!"                      │
│                                                   │
└───────────────────────────────────────────────────┘
```

### STAR 구조 가이드 (경험 등록 폼 내 인라인)

| STAR 요소 | 설명 | 예시 |
|-----------|------|------|
| **S**ituation (상황) | 어떤 상황이었는지 | "마케팅 동아리에서 신입 부원 모집을 담당했다" |
| **T**ask (과제) | 내가 맡은 역할/목표 | "SNS 홍보를 통해 지원자 50명 이상 확보해야 했다" |
| **A**ction (행동) | 구체적으로 무엇을 했는지 | "인스타그램 릴스 콘텐츠 기획 + A/B 테스트 진행" |
| **R**esult (결과) | 어떤 성과를 냈는지 | "지원자 83명 확보, 전년 대비 166% 증가" |

> 각 필드 옆에 접이식 가이드 아이콘(?) 배치. 클릭 시 예시 표시.

    │
    ▼
┌───────────────────────────────────────────────┐

│                                               │

│   주 무기: #문제해결  부 무기: #리더십 #소통     │
│                                               │
│   [채용공고 분석하러 가기 →]                    │
│                                               │
│   "경험이 많을수록 매칭 정확도가 올라갑니다"     │
│   [경험 더 추가하기]                            │
│                                               │

## 3. 첫 기업 분석 체험 (Aha Moment)

> **Aha Moment 정의**: "채용공고 URL 하나로 이렇게 깊은 분석이 가능하구나!"
> 이 순간을 경험해야 서비스 가치를 체감하고 재방문/결제로 이어짐

### 체험 유도 시나리오

```
[경험 1개 이상 등록 완료]
    │
    ▼
[기업 분석 유도 CTA]
    │
    ├── 사용자가 직접 URL 입력
    │
    └── 샘플 URL 제공 (원클릭 체험)
          │
          ├── "삼성전자 마케팅 신입 공채"
          ├── "네이버 서비스 기획 신입"
          ├── "현대자동차 연구개발 인턴"
          └── "카카오 프론트엔드 개발 신입"
    │
    ▼
[분석 결과 표시]
    │
    ├── 기업 분석 리포트 (일반)
    │
    └── ★ "내 경험 적합도" 섹션 하이라이트 (신규 사용자 전용)
          │
          ├── 적합도 높은 경험: 초록색 하이라이트 + 축하 메시지
          │     "마케팅 공모전 경험이 이 기업에 잘 맞습니다! (적합도 92%)"
          │
          └── 적합도 낮은 부분: 개선 안내
                "리더십 관련 경험을 추가하면 적합도를 높일 수 있어요"
```

### 첫 분석 완료 후 넛지

```
[첫 기업 분석 완료]
    │
    ▼
┌───────────────────────────────────────────────────┐
│ 분석이 완료되었습니다!                              │
│                                                   │
│ 다음 단계:                                        │
│   1. [이 기업에 맞는 자소서 쓰기 →] ← 메인 CTA    │
│   2. [다른 기업도 분석해보기]                       │
│   3. [경험 더 추가하기]                            │
│                                                   │
│ 무료 체험: 기업 분석 0/1회 사용 완료               │
│ "추가 분석은 스타터 회원부터 가능합니다"            │
└───────────────────────────────────────────────────┘
```

## 4. 재방문 유저 플로우

> 재방문 사용자는 이전 활동 맥락에서 자연스럽게 이어갈 수 있어야 함

### 마지막 활동 기반 진입점

| 마지막 활동 | 대시보드 CTA | 메시지 |
|------------|------------|--------|
| 기업 분석 완료 후 이탈 | 자소서 작성 유도 | "삼성전자 분석 결과를 바탕으로 자소서를 작성해보세요" |
| 자소서 초안 작성 중 이탈 | 에디터 이어가기 | "작성 중인 삼성전자 자소서를 이어서 작성하세요" |
| 첨삭 완료 후 이탈 | 다른 기업 분석 유도 | "삼성전자 자소서 완성! 다른 기업도 준비해볼까요?" |
| 경험만 등록 후 이탈 | 기업 분석 유도 | "등록한 경험으로 기업 분석을 시작해보세요" |
| 7일 이상 미접속 | 새로운 공채 시즌 안내 | "지금이 하반기 공채 시즌! 준비 시작해볼까요?" |

### 대시보드 최근 활동 카드

```
┌───────────────────────────────────────────────────┐
│ 최근 활동                                         │
│                                                   │
│ ┌─────────────────┐  ┌─────────────────┐         │
│ │ 삼성전자         │  │ 네이버           │         │
│ │ 마케팅 직무      │  │ 기획 직무        │         │
│ │ ■ 분석 완료      │  │ ■ 자소서 작성중   │         │
│ │ 적합도: 78%     │  │ 1/4 문항 완료    │         │
│ │ 2일 전          │  │ 5일 전           │         │
│ │ [자소서 쓰기 →] │  │ [이어서 쓰기 →]  │         │
│ └─────────────────┘  └─────────────────┘         │
│                                                   │
│ [+ 새 기업 분석하기]                               │
└───────────────────────────────────────────────────┘
```

### 알림/리마인더 정책

| 트리거 | 채널 | 메시지 | 빈도 제한 |
|--------|------|--------|----------|
| 작성 중 자소서 존재 + 3일 미접속 | 이메일 | "작성 중인 자소서가 기다리고 있어요" | 주 1회 |
| 마감일 D-7 | 이메일 + 인앱 | "삼성전자 마감일이 7일 남았습니다" | 해당 건 1회 |
| 마감일 D-1 | 인앱 | "내일이 마감일입니다!" | 해당 건 1회 |
| 공채 시즌 시작 | 이메일 | "상반기 공채 시즌이 시작되었습니다" | 시즌당 1회 |

> **수신 거부**: 모든 알림은 설정 페이지에서 개별 on/off 가능. 이메일 하단 수신거부 링크 필수.

## 5. 다중 기업 지원 시나리오

> 취준생은 평균 5~15개 기업에 동시 지원. 체계적 관리가 핵심 가치

### 데이터 모델 관점

```
[사용자]
    │
    ├── [경험 Bank] ──── 공유 자산 (모든 기업에서 활용)
    │     ├── 마케팅 공모전 경험
    │     ├── 인턴 경험
    │     └── 스터디 리더 경험
    │
    └── [지원 현황] ──── 기업별 독립 관리
          ├── 삼성전자 (분석 완료, 자소서 작성중)
          │     ├── 기업 분석 리포트
          │     ├── 자소서 문항 1 (초안 완료)
          │     ├── 자소서 문항 2 (작성중)
          │     └── 자소서 문항 3 (미시작)
          │
          ├── 네이버 (분석 완료, 자소서 미시작)
          │     └── 기업 분석 리포트
          │
          └── 현대자동차 (관심 등록)
                └── (분석 전)
```

### 경험 재사용 시 UX

동일한 경험을 여러 기업 자소서에 사용할 때:

```
[삼성전자 자소서 - 문항 1에서 "마케팅 공모전" 경험 선택]
    │
    ▼
[안내 표시]
    "이 경험은 네이버 자소서에서도 사용 중입니다."
    "같은 경험이라도 기업에 맞게 다른 각도로 작성할 수 있어요."
    │
    ├── [기업 맞춤 초안 새로 받기] ← 기업별 다른 초안 생성
    └── [네이버 버전 참고하기] ← 이전 작성본 사이드 패널로 표시
```

## 6. 온보딩 성공 지표

| 지표 | 목표 | 측정 방법 |
|------|------|----------|
| 프로필 완성률 | 70%+ | 가입 후 7일 내 프로필 2단계 완료 비율 |
| 첫 경험 등록 전환율 | 60%+ | 가입 후 7일 내 경험 1개 이상 등록 비율 |
| 첫 기업 분석 도달율 | 40%+ | 가입 후 7일 내 기업 분석 1회 이상 실행 비율 |
| D1 리텐션 | 30%+ | 가입 다음 날 재방문 비율 |
| D7 리텐션 | 20%+ | 가입 후 7일 이내 재방문 비율 |
| 온보딩 완료율 (3단계 모두) | 30%+ | 프로필 + 경험 + 기업 분석 모두 완료 비율 |
