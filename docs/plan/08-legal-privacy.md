## 1. 개인정보 수집 및 처리

### 수집 항목

| 구분 | 수집 항목 | 수집 방법 | 필수/선택 |
|------|----------|----------|----------|
| **가입 정보** | 이메일, 소셜 로그인 ID | Supabase Auth | 필수 |
| **프로필 정보** | 닉네임, 학년/상태 | 사용자 입력 | 필수 |
| **목표 정보** | 희망 직무, 희망 산업, 관심 기업 규모 | 사용자 입력 | 선택 |
| **경험 정보** | 경험 제목, 기간, 역할, STAR 구조 내용, 성과 | 사용자 입력 | 서비스 이용 시 필수 |
| **자소서 내용** | 문항, 답변 텍스트, 코칭 결과 | 사용자 입력 + AI 생성 | 서비스 이용 시 필수 |
| **이용 정보** | 서비스 이용 기록, 접속 로그, 기기 정보 | 자동 수집 | 필수 |
| **결제 정보** | 결제 수단, 결제 이력 | Toss Payments 연동 | 유료 이용 시 필수 |

> **민감 정보**: 경험 내용과 자소서에 개인 민감 정보(실명, 학교명, 회사명 등)가 포함될 수 있음. AI API 전송 시 이 점을 사용자에게 안내해야 함.

### 처리 목적

| 처리 목적 | 관련 데이터 | 법적 근거 |
|----------|-----------|----------|
| 회원 관리 및 서비스 제공 | 가입 정보, 프로필 | 계약 이행 |
| AI 기업 분석 및 코칭 | 경험, 자소서, 목표 정보 | 계약 이행 + 동의 |
| 경험-공고 매칭 (임베딩) | 경험 내용, 공고 정보 | 계약 이행 |
| 서비스 개선 및 통계 | 이용 기록 (비식별 처리) | 정당한 이익 |
| 결제 처리 | 결제 정보 | 계약 이행 |

### 보관 및 삭제 정책

| 데이터 | 보관 기간 | 삭제 방법 |
|--------|----------|----------|
| 회원 정보 | 회원 탈퇴 시 30일 이내 | 자동 삭제 (soft delete 30일 → hard delete) |
| 경험/자소서 | 회원 탈퇴 시 30일 이내 | 자동 삭제 |
| 코칭 세션 로그 | 생성일로부터 6개월 | 자동 삭제 (배치 처리) |
| 기업 분석 캐시 | 7일 TTL | 자동 만료 삭제 |
| 임베딩 벡터 | 원본 경험 삭제 시 함께 삭제 | 연쇄 삭제 |
| 결제 이력 | 관계 법령에 따라 5년 | 전자상거래법 준수 |
| 접속 로그 | 3개월 | 통신비밀보호법 준수 |

### 제3자 제공

| 항목 | 내용 |
|------|------|
| 제3자 제공 | **없음** |
| 데이터 처리 위탁 | AI API 제공사 (아래 섹션 2 상세) |

## 2. AI API 데이터 처리 위탁

> AI API를 통해 사용자 데이터가 외부로 전송됨. 이는 개인정보 처리 위탁에 해당하며, 투명하게 고지해야 함.

### AI 제공사별 데이터 정책

| 제공사 | 모델 | 용도 | 데이터 학습 여부 | 데이터 보관 | 확인 사항 |
|--------|------|------|----------------|-----------|----------|
| **Anthropic** | Claude Sonnet 4.5 | 기업 분석, 문항 분석, 초안/첨삭 코칭 | API를 통한 입출력 데이터 학습에 미사용 | 30일 보관 후 삭제 (API Terms) | 최신 API Terms 확인 필요 |
| **Google / Groq** | Gemini Flash / Groq Llama | 공고 파싱, 무기 태깅, AI 인터뷰 | API 사용 시 기본 opt-out (Google AI Studio: 학습 미사용, Groq: 학습 미사용) | 30일 보관 후 삭제 | 각 제공사 최신 API Terms 확인 필요 |
| **OpenAI** | text-embedding-3-small | 경험 임베딩 생성 | API 사용 시 기본 opt-out | 30일 보관 후 삭제 | 동일 |

### AI 전송 데이터 최소화 원칙

```
[사용자 데이터]
    │
    ├── AI에 전송하는 데이터 (최소화)
    │     ├── 경험 내용 (STAR 구조) ── 코칭에 필수
    │     ├── 자소서 텍스트 ── 첨삭에 필수
    │     ├── 공고 내용 (파싱 결과) ── 분석에 필수
    │     └── 목표 직무/산업 ── 맞춤 분석에 필수
    │
    └── AI에 전송하지 않는 데이터
          ├── 이메일 주소
          ├── 실명 (수집하지 않음)
          ├── 결제 정보
          └── 접속 로그
```

### 사용자 안내 문구

AI 코칭 기능 최초 사용 시 동의 화면:

```
┌───────────────────────────────────────────────────┐
│ AI 코칭 서비스 안내                                │
│                                                   │
│ Colight는 AI 코칭을 위해 다음 데이터를 AI          │
│ (Claude, Gemini, Groq)에 전송합니다:                │

│  - 등록하신 경험 내용                              │
│  - 자소서 문항 및 답변                             │
│  - 채용공고 분석 결과                              │

│ ✓ 이메일, 실명 등 식별 정보는 전송하지 않습니다     │

└───────────────────────────────────────────────────┘
```

## 3. 크롤링 법적 근거

> 채용공고 크롤링은 서비스의 핵심 기능. 법적 리스크를 최소화하는 원칙 수립

### 크롤링 3원칙

| 원칙 | 설명 | 구현 방법 |
|------|------|----------|
| **1. 사용자 요청 기반** | 봇이 아닌, 사용자가 URL을 직접 입력하여 요청 | URL 입력 필드 + 사용자 액션으로만 크롤링 시작 |
| **2. 1건만 fetch** | 대량 크롤링 아닌, 입력된 1개 URL만 단일 요청 | 배치 크롤링 기능 없음, Rate Limit: 1건/요청 |
| **3. 원문 미저장** | 크롤링한 HTML 원문을 DB에 저장하지 않음 | 파싱 결과(구조화 데이터)만 저장, 원문은 메모리 처리 후 폐기 |

### 사이트별 크롤링 전략

| 사이트 | 방식 | robots.txt 준수 | 공식 API | 비고 |
|--------|------|-----------------|---------|------|
| 잡코리아 | Cheerio (정적 HTML) | 준수 | 없음 | 공개 공고 페이지만 접근 |
| 원티드 | Playwright (SPA) | 준수 | 비공개 | River 비동기 처리 (Phase 10) |
| 캐치 | Cheerio (정적 HTML) | 준수 | 없음 | 공개 공고 페이지만 접근 |
| 사람인 | **공식 API 우선** | - | 있음 (oAPI) | API로 대체 가능한 경우 API 사용 |
| DART | **공식 API** | - | 있음 (OpenAPI) | 기업 정보 전용 |

### robots.txt 준수 구현

```
[크롤링 요청]
    │
    ├── 1. 해당 도메인 robots.txt 확인 (캐시 24시간)
    │     └── 요청 경로가 Disallow에 해당 → 크롤링 중단 + 수동 입력 안내
    │
    ├── 2. User-Agent 설정
    │     └── "Mozilla/5.0 (compatible; Colight/1.0)" ← 봇 식별 가능하도록
    │     ※ 일반 브라우저 User-Agent 사칭하지 않음
    │
    └── 3. 요청 빈도 제한
          └── 동일 도메인에 대해 최소 1초 간격
```

### 관련 법률 검토

| 법률 | 적용 여부 | 리스크 수준 | 대응 |
|------|----------|-----------|------|
| **데이터베이스 보호법** (저작권법 제93조) | 낮음 | 낮음 | 1건 단위 접근, 데이터베이스 전체 복제 아님 |
| **부정경쟁방지법** 제2조 제1호 차목 | 검토 필요 | 중간 | 사용자 요청 기반 + 원문 미저장 + 1건/요청으로 최소화 |
| **저작권법** (공고 텍스트 저작물성) | 낮음 | 낮음 | 채용공고는 사실 전달 목적, 저작물성 약함 (판례 경향) |
| **컴퓨터 프로그램 보호법** | 해당 없음 | - | 웹 페이지 접근, 프로그램 역분석 아님 |
| **정보통신망법** | 검토 필요 | 낮음 | 공개 페이지 접근, 로그인 우회 없음 |

> **핵심**: "사용자가 직접 URL을 입력하여 1건의 공개된 채용공고를 조회"하는 행위는 일반 사용자가 브라우저로 접근하는 것과 동일한 수준. 대량 크롤링/스크래핑과는 법적 성격이 다름.

## 4. AI 생성 콘텐츠 저작권

### 저작권 귀속 원칙

| 콘텐츠 | 저작권 | 근거 |
|--------|--------|------|
| AI 코칭 초안 | **사용자 귀속** | 사용자의 경험 + 지시로 생성된 결과물 |
| AI 첨삭 피드백 | **서비스 참고 자료** | AI가 생성한 조언/피드백 |
| 기업 분석 리포트 | **서비스 참고 자료** | 공개 데이터 + AI 분석 |
| 사용자가 수정/완성한 자소서 | **사용자 귀속** | 사용자의 창작 결과물 |

> **현행 한국 저작권법 관점**: AI 생성물의 저작물성은 아직 명확한 법적 판단이 없음. 사용자가 AI 도구를 활용하여 창작한 결과물에 대해서는 사용자의 창작 기여도를 인정하는 방향으로 해석.

### 이용약관 고지 문구

```
[AI 코칭 관련 이용약관 조항]

제X조 (AI 코칭 서비스)
1. 본 서비스의 AI 코칭 기능은 자소서 작성을 보조하는 도구이며,
   최종 결과물의 작성 및 활용에 대한 책임은 사용자에게 있습니다.

2. AI 코칭 결과는 참고 자료로서, 채용 과정의 합격을 보장하지 않습니다.

3. 사용자는 AI 코칭 결과를 자유롭게 수정, 활용할 수 있으며,
   이에 대한 저작권은 사용자에게 귀속됩니다.

4. 서비스는 AI 코칭 품질 개선을 위해 비식별 처리된 통계 데이터를
   활용할 수 있습니다. (개별 자소서 내용은 사용하지 않음)
```

### AI 생성 콘텐츠 표시 의무

서비스 내에서 AI가 생성한 콘텐츠에는 명확한 표시 필요:

| 위치 | 표시 방법 |
|------|----------|
| AI 초안 코칭 결과 | "AI가 제안한 초안입니다. 본인의 문체로 수정해주세요." 헤더 |
| AI 첨삭 피드백 | "AI 코칭 피드백" 라벨 |
| 기업 분석 리포트 | "AI 분석 결과이며, 실제와 다를 수 있습니다." 하단 고지 |
| 서비스 전반 | 하단 고정 텍스트: "Colight는 AI 코칭 도구입니다" |
