## 1. 경험 관리 (Experience Bank)

> 취준생의 가장 근본적 문제 "쓸게 없다"를 해결

### 핵심 기능

| 기능 | 설명 | 왜 필요한가 |
|------|------|------------|
| **경험 등록** | 인턴, 프로젝트, 대외활동, 아르바이트 등을 STAR 구조로 등록 | 현재 노션/엑셀 수동 관리의 비효율 해소 |
| **AI 경험 인터뷰** | 대화형으로 경험을 끌어내는 AI 코칭 | 취준생 스스로 못 찾는 경험의 가치를 발굴 |
| **역량 태그 자동 분류** | 등록된 경험에서 리더십, 문제해결, 소통 등 역량 키워드 자동 추출 | 직무별 필요 역량과 빠른 매칭 |
| **경험 활용 이력** | 이 경험을 어떤 기업, 어떤 문항에, 어떤 각도로 사용했는지 추적 | 같은 경험 반복 사용 방지, A/B 비교 가능 |

### UX 플로우

```
[경험 추가하기]
    |
    ├── 직접 입력 (폼 기반: 제목, 기간, 내용, 성과)
    |
    └── AI 인터뷰 (대화형)
         "어떤 활동이었나요?" → "가장 어려웠던 점은?" → "어떻게 해결했나요?" → "결과는?"
         → AI가 STAR 구조로 자동 정리 → 사용자 확인/수정
    |
    v
[경험 카드 생성]
    - 제목, 기간, STAR 구조화 내용
    - 자동 태그: #리더십 #데이터분석 #협업 #문제해결
    - 적합 직무 추천: "마케팅, 기획, PM에 활용도 높음"
```

## 2. 기업 분석 (Company Intelligence)

> 킬러 기능. "기업 분석이 핵심"

### 핵심 기능

| 기능 | 설명 | 데이터 소스 |
|------|------|------------|
| **공고 자동 분석** | URL 붙여넣기 → 직무, 자격요건, 우대사항, 핵심 키워드 자동 추출 | Cheerio/Playwright 파싱 |
| **기업 프로필** | 기업 기본정보, 재무현황, 규모 자동 조회 | DART OpenAPI |
| **인재상 분석** | 기업이 원하는 인재 특성 3~5가지 + 근거 | 사전 DB + AI 추론 |
| **최근 동향** | 최근 3개월 뉴스 요약 + 자소서 활용 포인트 | 네이버 뉴스 API |
| **전략 키워드** | 이 기업 자소서에 반드시 녹여야 할 키워드 5~7개 | AI 종합 분석 |
| **내 경험 적합도** | 내 경험 vs 기업 요구사항 매칭 점수 (%) | LLM 매칭 |

### UX 플로우

```
[채용공고 URL 붙여넣기]
    |
    v
[실시간 분석 (스트리밍)] ──── 15~30초
    |
    v
[기업 분석 리포트]
    ┌─────────────────────────────────────┐
    │ 삼성전자 - 마케팅 직무               │
    │                                     │
    │ ■ 핵심가치: 인재제일, 기술혁신, 변화선도 │
    │ ■ 인재상: 창의적 사고, 데이터 기반 의사결정│
    │ ■ 최근 동향: AI 반도체 투자 확대...    │
    │ ■ 전략 키워드: #데이터분석 #소비자인사이트 │
    │                                     │
    │ ── 내 경험 매칭 ──                   │
    │ 종합 적합도: 78%                      │
    │  - 마케팅 공모전 (92%)               │
    │  - 데이터 분석 프로젝트 (85%)         │
    │  - 카페 아르바이트 (45%)             │
    │                                     │
    │ [이 기업에 맞는 자소서 쓰기 →]         │
    └─────────────────────────────────────┘
```

## 3. AI 자소서 코칭

> "대신 써주는 것"이 아닌 "코칭"

### 핵심 기능

| 기능 | 설명 |
|------|------|
| **문항 분석** | 자소서 문항의 의도 해석 + 이 문항에서 보여줘야 할 역량 가이드 |
| **경험 추천** | 기업 분석 + 문항 의도 기반으로, 내 경험 중 적합한 것 추천 (적합도 %) |
| **초안 코칭** | 선택한 경험으로 STAR 구조 초안 생성 → 사용자가 본인 문체로 수정 |
| **첨삭 코칭** | 작성 완료 자소서에 대해 구체성, 직무 적합성, 기업 맞춤도 피드백 |
| **AI 탐지 체크** | 작성된 자소서의 AI 생성 느낌 정도를 체크하고 개선 제안 |
| **글자수 조절** | 목표 글자수에 맞게 늘리기/줄이기 코칭 |

### 코칭 흐름

```
[자소서 작성하기]
    |
    ├── 기업 선택 (기업 분석 결과 연결)
    ├── 문항 입력 ("지원동기를 500자 이내로 작성하세요")
    |
    v
[AI 문항 분석]
    "이 문항은 '왜 이 기업인가' + '왜 이 직무인가'를 묻고 있어요.
     당신의 경험 중 이런 것들이 잘 맞을 것 같아요:"

    - 마케팅 공모전 경험 (적합도 92%)
    - SNS 콘텐츠 운영 경험 (적합도 78%)
    |
    v
[초안 코칭]
    AI가 STAR 구조 초안 제안 → 에디터에서 직접 수정
    |
    v
[첨삭 코칭]
    - 구체성: 60% → "성과를 수치로 표현하세요"
    - 직무적합: 80% → "마케팅 키워드가 잘 녹아있어요"
    - 기업맞춤: 65% → "삼성의 '변화선도' 가치를 더 반영해보세요"
    - 진정성: 95% → "본인만의 에피소드가 잘 드러나요"
```

## 4. 지원 대시보드

> 자소서 성과를 추적하고 학습하는 피드백 루프

| 기능 | 설명 |
|------|------|
| **지원 현황 칸반보드** | 관심 → 작성중 → 제출 → 서류합격 → 면접 → 최종 단계별 관리 |
| **마감일 알림** | 다가오는 채용 마감일 캘린더 뷰 |
| **자소서 버전 관리** | 기업별로 작성한 자소서를 저장, 어떤 버전을 제출했는지 추적 |
| **합격률 분석** | 합격/불합격 기록 기반, 어떤 경험/키워드가 합격에 기여했는지 인사이트 |
| **경험 활용 통계** | 어떤 경험이 가장 많이 사용되었고, 합격률은 어떤지 시각화 |
